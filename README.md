Современная **Material 3 Expressive** тёмная тема для Системы дистанционного обучения РАНХиГС (**lms.ranepa.ru**) с полноразмерной интерактивной **Paqa Studio (Песочницей тем)**.

---

## ⚡ Быстрая установка в 1 клик

Если у вас уже установлено расширение для юзерскриптов (*Tampermonkey*, *Violentmonkey* или *Userscripts* на iOS), просто нажмите на ссылку ниже:

👉 ### [**НАЖМИТЕ ЗДЕСЬ ДЛЯ УСТАНОВКИ СКРИПТА**](https://raw.githubusercontent.com/paqasupport/ranepa-moodle-theme/main/moodle-theme.user.js) 👈

*(Расширение автоматически перехватит ссылку и предложит нажать кнопку **«Установить»**).*

---

## ✨ Возможности

- 🌙 **Нативная глубокая тёмная тема** — создана по гайдлайнам Material 3, бережёт глаза при вечерней учёбе.
- 🎨 **Встроенная Paqa Studio (Песочница)** — вызывается в любой момент клавишами `Alt + S` или плавающей кнопкой 🎨 в углу экрана (кнопку можно свободно перетаскивать мышкои/пальцем в любое место).
- 🦅 **Оригинальный герб РАНХиГС** в шапке сайта.
- 🪄 **Интерактивный ластик** — скройте любые ненужные баннеры, подвалы или кнопки в один клик.
- 🖐️ **Перемещение элементов** — двигайте блоки расписания, дедлайнов и карточки так, как удобно вам.
- 🖼️ **Свои обложки и названия курсов** — ставьте понятные сокращения (например, «Матан» вместо длинного бюрократического названия) и свои картинки.
- 🔄 **Фоновые автообновления** — при выходе улучшений скрипт обновляется сам, при этом все ваши сохранённые цвета, настройки и пресеты **не слетают**!

## 📱 Пошаговая инструкция по установке

### 💻 1. Компьютер (Windows / macOS / Linux)
1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера (Chrome, Яндекс Браузер, Edge, Opera, Firefox).
2. Нажмите на [ссылку установки скрипта](https://raw.githubusercontent.com/paqasupport/ranepa-moodle-theme/main/moodle-theme.user.js).
3. В открывшейся вкладке Tampermonkey нажмите кнопку **«Установить»** (Install).
4. Перейдите на [lms.ranepa.ru](https://lms.ranepa.ru/) — тема применится автоматически!

---

### 🤖 2. Смартфоны на Android
*Стандартный Chrome на Android не поддерживает расширения, поэтому используем любой браузер с поддержкой дополнений:*

#### Вариант А: Яндекс Браузер (рекомендуется)
1. Установите **Яндекс Браузер** из Google Play.
2. Откройте страницу [Tampermonkey в Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkminghmkffffoojackbdaobpa) и нажмите **«Установить»**.
3. Перейдите по [ссылке установки скрипта](https://raw.githubusercontent.com/paqasupport/ranepa-moodle-theme/main/moodle-theme.user.js).
4. Нажмите **«Установить»** в окне Tampermonkey.

#### Вариант Б: Firefox для Android
1. Установите **Firefox** из Google Play.
2. Меню `⋮` $\to$ **Дополнения** $\to$ найдите и включите **Tampermonkey**.
3. Перейдите по [ссылке установки скрипта](https://raw.githubusercontent.com/paqasupport/ranepa-moodle-theme/main/moodle-theme.user.js) и подтвердите установку.

---

### 🍏 3. iPhone и iPad (iOS)

#### Через Safari (приложение Userscripts)
1. Установите бесплатное приложение **[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)** из App Store.
2. Откройте **Настройки** iPhone $\to$ **Приложения** $\to$ **Safari** $\to$ **Расширения** $\to$ включите **Userscripts** и поставьте галочку *«Всегда разрешать»*.
3. Откройте Safari и перейдите по [ссылке установки скрипта](https://raw.githubusercontent.com/paqasupport/ranepa-moodle-theme/main/moodle-theme.user.js).
4. Нажмите на значок расширений в строке Safari (иконка `🧩` или `аА`) $\to$ выберите **Userscripts** $\to$ нажмите **«Install User Script»**.
5. Зайдите на [lms.ranepa.ru](https://lms.ranepa.ru/) — тема активна!

## ⌨️ Горячие клавиши
- `Alt + S` (или русская `Alt + Ы`) — открыть / закрыть Paqa Studio (Песочницу).
- Плавающая круглая кнопка **🎨** в правом нижнем углу — альтернативное открытие песочницы (зажмите и тяните, чтобы переместить кнопку).
